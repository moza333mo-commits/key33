# ⌨️ LinguaKey v3.0 (Gboard Edition) — لوحة المفاتيح الذكية بمعاينة الترجمة الفورية

**LinguaKey v3.0** هي لوحة مفاتيح أندرويد احترافية وسريعة جداً بتصميم مطابق بصرياً لـ **Google Gboard**، مزوّدة بنظام **معاينة الترجمة الذكي قبل الإرسال (On-Demand Translation Preview)** المدعوم بمحرك **Google Gemini API**.

---

## ✨ أبرز التطويرات في الإصدار v3.0 (Gboard Edition)

1. **نظام الكتابة والمعاينة الآمن (بدون استبدال تلقائي للنص الأصلي)**:
   - تكتب بلغتك الأصلية (العربية الفصحى أو **اللهجة السورية/الشامية الطبيعية**) داخل شريط الكتابة العادي في WhatsApp أو HelloTalk أو Telegram.
   - يظل نصك الأصلي ظاهراً وقابلاً للتعديل بالكامل أثناء الكتابة دون أي تدخل أو استبدال مفاجئ.
   - عند الضغط على زر **`🌐 ترجمة`** في الشريط النحيف، تتم معالجة الجملة وعرض الترجمة المقترحة + البدائل في **بطاقة معاينة مستقلة وواضحة**.
   - يمكنك مراجعة الترجمة قبل إرسالها والاختيار بين:
     - **`✓ اعتماد الترجمة`**: لاستبدال النص بالترجمة المختارة فوراً.
     - **`إبقاء النص الأصلي`**: لإغلاق المعاينة وإرسال نصك الأصلي كما هو.
     - **`↩ تراجع`**: لاستعادة النص الأصلي حتى بعد اعتماد الترجمة.

2. **واجهة Gboard نظيفة وقائمة أدوات مستقلة (`⊞`)**:
   - أزلنا ازدحام الشريط العلوي بالكامل؛ لم يتبقَّ سوى شريط نحيف يضم زر الأدوات **`⊞`**، ومؤشر اللغات **`AR ⇄ EN`**، وزر **`🌐 ترجمة`**.
   - عند الضغط على زر **`⊞`** تفتح **قائمة الأدوات المستقلة** التي تضم جميع المزايا المتقدمة (الحافظة Clipboard، مساعد الذكاء الاصطناعي AI Copilot، لوحة الإيموجي، البحث عن GIF، اختيار اللهجة الشامية/الرسمية، تحسين الصياغة، والإعدادات).

3. **توزيع الشريط السفلي على طريقة Gboard**:
   - توحيد زر الرموز والأرقام إلى **`?123`** بدلاً من الأرقام المزدحمة.
   - إضافة **زر الإيموجي المستقل (`😀`)** بجانب زر تبديل اللغة (`🌐`) مباشرة في الصف السفلي لسهولة التنقل بين اللغات والإيموجي بلمسة واحدة، مع زر **`ABC`** داخل لوحة الإيموجي للعودة الفورية.

4. **تحسينات شاملة في الأداء واستهلاك الذاكرة والبطارية**:
   - إلغاء قراءة `SharedPreferences` المتكررة من دالة رسم المفاتيح `onDrawKeyboard()` لضمان استجابة لمس فورية (60fps–120fps).
   - إزالة استدعاء `System.gc()` من مسار إغلاق اللوحة لمنع أي تجمّد أثناء التنقل السريع بين التطبيقات.
   - تخزين فئات الإيموجي مؤقتاً (`Cached View Rows`) لتفتح لوحة الإيموجي في `0ms`.

## 📦 الفرق بين نسختَي البناء (`MlKit` و `NoMlKit`)

ينتج نظام البناء في GitHub Actions نسختين جاهزتين للتثبيت داخل حزمة `LinguaKey-Installable-APKs`:

| النسخة | اسم ملف الـ APK الناتج | المميزات ومتى تختارها؟ |
| :--- | :--- | :--- |
| **نسخة `NoMlKit` (موصى بها)** | `app-nomlkit-debug.apk` | **خفيفة جداً وسريعة (حجم صغير واستهلاك ذاكرة أقل)**؛ تعتمد على **Gemini API** والترجمة السحابية الفورية بدون مكتبات Google ML Kit الثقيلة. |
| **نسخة `MlKit` (الشاملة)** | `app-mlkit-debug.apk` | تتضمن نفس مزايا `NoMlKit` بالكامل **بالإضافة إلى مكتبة Google ML Kit** لتنزيل قواميس الترجمة المحلية على الهاتف واستخدامها **بدون إنترنت نهائياً (Offline)**. |

## 🚀 طريقة الرفع السريع من متصفح Chrome إلى GitHub (تجاوز حد الـ 100 ملف)

1. حمّل ملف **`LinguaKey-GitHub-Web-Upload-key5.zip`** وفك ضغطه على جهازك؛ ستجد بداخله **3 عناصر فقط**:
   - مجلد **`.github`**
   - ملف **`LinguaKey-Payload.zip`** *(اتركه مضغوطاً كما هو ولا تفك ضغطه!)*
   - ملف **`README.md`**
2. افتح مستودعك على GitHub من متصفح Chrome، واضغط **Add file** ⬅ **Upload files**.
3. اسحب العناصر الـ 3 معاً وأفلتها في المتصفح ثم اضغط **Commit changes**.
4. سيتولى **GitHub Actions** تلقائياً فك ضغط الـ 831 ملفاً بترتيبها الكامل داخل المستودع وبناء ملفات الـ **APK** الجاهزة للتثبيت في تبويب **Actions** تحت قسم **Artifacts** (`LinguaKey-Installable-APKs`).
