# 🚀 نسخة الرفع السريع والمضمون (Pure Java v3.0 - Gboard Edition)

تم تحويل جميع كلاسات المشروع إلى **Java النقية 100% (Pure Java)** وإزالة إضافة `kotlin-android` التي تسببت بفشل خطوة التجميع في البناء السابق على GitHub Actions.

---

## ⚡ طريقة الرفع إلى مستودعك (`key7` أو أي مستودع جديد) من متصفح Chrome:

1. فك ضغط هذا الملف (`LinguaKey-GitHub-Web-Upload-key7.zip`) في مجلد فارغ؛ ستجد بداخله **3 عناصر فقط**:
   - 📁 مجلد **`.github`** (وبداخله `.github/workflows/main.yml`)
   - 📦 ملف **`LinguaKey-Payload.zip`** *(اتركه مضغوطاً كما هو ولا تفك ضغطه!)*
   - 📄 ملف **`README.md`**
2. افتح مستودعك على GitHub واضغط **Add file** ⬅ **Upload files**.
3. اسحب العناصر الـ 3 معاً وأفلتها في المتصفح ثم اضغط **Commit changes**.
4. سيتولى **GitHub Actions** فك الضغط وبناء نسختَي الـ APK (`app-nomlkit-debug.apk` و`app-mlkit-debug.apk`) بنجاح 100% تحت قسم **Artifacts** (`LinguaKey-Installable-APKs`).
